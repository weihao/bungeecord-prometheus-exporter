`minecraft_proxy` is the default namespace; change it with the `namespace` setting.
Standard `jvm_*` and `process_*` metrics come from the Prometheus JVM instrumentation
and are deliberately not namespaced, so ordinary JVM dashboards work unchanged.

| Metric | Type | Labels | Description |
| --- | --- | --- | --- |
| `minecraft_proxy_chat_messages_total` | counter | - | Chat messages sent through the proxy, excluding commands |
| `minecraft_proxy_commands_total` | counter | `command` | Commands executed through the proxy, labelled by command root |
| `minecraft_proxy_connections_total` | counter | - | Connections accepted by the proxy, before authentication |
| `minecraft_proxy_disconnects_total` | counter | - | Players that disconnected from the proxy |
| `minecraft_proxy_exporter_build_info` | gauge | `bungeecord_api`, `java_target`, `prometheus_client`, `velocity_api`, `version` | Build information for the proxy Prometheus exporter |
| `minecraft_proxy_exporter_sampler_duration_seconds` | histogram | `sampler` | Wall time taken by each background sampler run |
| `minecraft_proxy_exporter_sampler_runs_total` | counter | `result`, `sampler` | Background sampler executions by outcome |
| `minecraft_proxy_info` | gauge | `name`, `online_mode`, `type`, `version` | Proxy identity. Always 1; the information is in the labels |
| `minecraft_proxy_kicks_total` | counter | `server` | Players kicked from a backend server |
| `minecraft_proxy_list_pings_total` | counter | - | Server-list pings answered by the proxy, i.e. clients viewing the MOTD |
| `minecraft_proxy_logins_total` | counter | `result` | Login attempts by outcome: allowed or denied |
| `minecraft_proxy_player_latency_seconds` | gauge | `player`, `server`, `uuid` | Round-trip latency of each connected player. High cardinality: one series per player |
| `minecraft_proxy_player_online` | gauge | `player`, `server`, `uuid` | Always 1 for each connected player. High cardinality: one series per player |
| `minecraft_proxy_player_ping_seconds` | histogram | - | Distribution of player round-trip latency, sampled on an interval |
| `minecraft_proxy_players_online` | gauge | - | Players currently connected to the proxy |
| `minecraft_proxy_plugin_info` | gauge | `plugin`, `version` | Always 1 for each loaded plugin. The information is in the labels |
| `minecraft_proxy_plugins_installed` | gauge | - | Plugins loaded by the proxy |
| `minecraft_proxy_redis_players_online` | gauge | - | Players online across the whole network, as reported by RedisBungee. Identical on every proxy; do not sum across instances |
| `minecraft_proxy_redis_proxies_online` | gauge | - | Proxies participating in the RedisBungee network |
| `minecraft_proxy_server_info` | gauge | `address`, `server` | Always 1 for each registered backend server. The information is in the labels |
| `minecraft_proxy_server_ping_seconds` | gauge | `server` | Round-trip time of the last successful server-list ping to the backend |
| `minecraft_proxy_server_players_online` | gauge | `server` | Players connected to the proxy, by backend server |
| `minecraft_proxy_server_reported_max_players` | gauge | `server` | Slot limit the backend reported in its last ping response |
| `minecraft_proxy_server_reported_players` | gauge | `server` | Player count the backend reported in its last ping response. May differ from the proxy's own count if players connect to the backend directly |
| `minecraft_proxy_server_switches_total` | counter | `from`, `to` | Players moving between backend servers |
| `minecraft_proxy_server_up` | gauge | `server` | 1 if the backend server answered its last server-list ping, 0 if it did not |
| `minecraft_proxy_servers_registered` | gauge | - | Backend servers registered with the proxy |
| `minecraft_proxy_start_time_seconds` | gauge | - | Unix timestamp at which the exporter started |
| `minecraft_proxy_uptime_seconds` | gauge | - | Seconds since the exporter started |

## Enabled by default

- `metrics.jvm`
- `metrics.proxy-info`
- `metrics.players-online`
- `metrics.players-per-server`
- `metrics.player-ping-histogram`
- `metrics.servers`
- `metrics.backend-health`
- `metrics.plugins`
- `metrics.events`

## Disabled by default

- `metrics.player-ping-per-player` — **high cardinality**: one series per player
- `metrics.player-list` — **high cardinality**: one series per player
- `metrics.command-label` — **high cardinality**: one series per distinct command, and commands are player input
- `metrics.redisbungee`
