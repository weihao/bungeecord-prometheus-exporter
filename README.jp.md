# Proxy Prometheus Exporter

Velocity / BungeeCord / Waterfall プロキシ用の Prometheus エクスポーターです。

完全なドキュメントは現在英語版のみです：**[README.md](README.md)**。

クイックスタート：jar をプロキシの `plugins/` に置いて起動するだけで、
`http://<host>:9985/metrics` でメトリクスを取得できます。
