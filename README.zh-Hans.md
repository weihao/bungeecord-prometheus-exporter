# Proxy Prometheus Exporter

Velocity / BungeeCord / Waterfall 代理服务器的 Prometheus 监控插件。

完整文档目前只有英文版：**[README.md](README.md)**。

快速开始：将 jar 放入代理服务器的 `plugins/` 目录并启动，指标即可在
`http://<host>:9985/metrics` 访问。
